# เว็บบอกรัก ฮัฌ & ฝ้าย

รหัสเข้าเว็บ: วันครบรอบ 6 หลัก (วว ดด ปป พ.ศ.)

## ขึ้น GitHub Pages
1. สร้าง repo ใหม่บน github.com (เช่นชื่อ `for-fai`) — ต้องเป็น Public สำหรับบัญชีฟรี
2. กด Add file → Upload files แล้วลากไฟล์/โฟลเดอร์ในนี้ทั้งหมดเข้าไป (index.html ต้องอยู่ชั้นนอกสุด) → Commit
3. Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save
4. รอ 1–2 นาที ลิงก์คือ https://ชื่อผู้ใช้.github.io/ชื่อrepo/
